# Multiple-Disease-Prediction
Multiple Disease Prediction using Machine Learning is a project that uses patient medical data to train ML models (like Logistic Regression, Random Forest, and SVM) for predicting the risk of diseases such as diabetes, heart disease, and Parkinson’s, and integrates them into a single dashboard for quick and efficient healthcare decision support.
This predicts  84.6 % accuracy , 84.6% recall , 91.7% F1 score 75.4% test accuracy
